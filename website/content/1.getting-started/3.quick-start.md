---
title: Quick Start
description: Go from an existing Supabase table to your first typed fetch in a few steps.
---

This guide assumes you already have a Nuxt app, a Supabase project, and an `exampleTable` table protected by appropriate RLS policies.

## 1. Install NSDB

```bash
npm install @lucashw68/nsdb @nuxtjs/supabase @pinia/nuxt pinia
npm install --save-dev supabase
```

## 2. Add the Nuxt modules

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@lucashw68/nsdb',
    '@pinia/nuxt',
    '@nuxtjs/supabase',
  ],
})
```

## 3. Configure Supabase

```bash [.env]
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key
SUPABASE_PROJECT_ID=your-project-id
```

## 4. Initialize NSDB

Run this from the Nuxt application root:

```bash
npx nsdb init
```

Review the generated `nsdb.config.ts`. Prefer an explicit table allowlist for browser-facing artifacts:

```ts [nsdb.config.ts]
import type { NsdbConfig } from '@lucashw68/nsdb/types/config'

export default {
  supabase: {
    schema: 'public',
    projectId: process.env.SUPABASE_PROJECT_ID,
  },
  tables: {
    include: ['exampleTable'],
  },
} satisfies NsdbConfig
```

## 5. Generate the client layer

```bash
npx nsdb generate:all
```

Generation writes database types, PostgreSQL metadata when available, schemas, models, optional stores, and the generic model registry.

## 6. Fetch your first rows

```vue [app/pages/example.vue]
<script setup lang="ts">
const exampleTable = useExampleTable()

await exampleTable.fetch()
</script>

<template>
  <ul>
    <li v-for="entry in exampleTable.items.value" :key="entry.id">
      {{ entry.title }}
    </li>
  </ul>
</template>
```

::callout{type="note" title="Vue refs"}
Generated model state is reactive. Script code reads `exampleTable.items.value`.
::

## Or start with generic UI

```vue
<NsdbList model="exampleTable" />
<NsdbForm model="exampleTable" />
```

Continue with [Direct vs Store](/docs/core/direct-vs-store) before choosing shared cache behavior.
