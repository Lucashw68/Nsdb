---
title: Remote Generation
description: Generate Supabase types over trusted SSH when PostgreSQL is reachable only on a remote host.
badge: Advanced
---

Remote generation is available when the database is reachable from a trusted VPS but not from the local machine.

```ts [nsdb.config.ts]
export default {
  supabase: {
    schema: 'public',
    remoteTypes: {
      sshHost: process.env.SUPABASE_REMOTE_SSH_HOST,
      projectPath: process.env.SUPABASE_REMOTE_PROJECT_PATH,
      dbUrl: process.env.SUPABASE_REMOTE_DB_URL,
      remoteOutput: '/tmp/database.types.ts',
      beforeCommand: process.env.SUPABASE_REMOTE_BEFORE_COMMAND,
      supabaseCommand: process.env.SUPABASE_REMOTE_SUPABASE_COMMAND,
    },
  },
}
```

NSDB runs the configured Supabase CLI command through SSH, writes the remote types file, then copies it locally with `scp`.

```bash
npx nsdb init --remote-types
npx nsdb generate:all
```

::callout{type="warning" title="Trusted developer configuration"}
Remote command fragments execute in the developer environment. Treat `nsdb.config.ts` and its environment values as trusted build input.
::

Use `beforeCommand` when a non-interactive SSH shell must load Node, for example `source ~/.nvm/nvm.sh`. `supabaseCommand` defaults to `npx supabase`.
