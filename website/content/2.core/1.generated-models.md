---
title: Generated Models
description: Use the canonical typed state and operations generated for every exposed table.
---

For an exposed `exampleTable` table, NSDB generates a `useExampleTable()` hook. It binds the table's database types, metadata, primary key, and relations to the generic runtime.

```ts
const exampleTable = useExampleTable({ store: true })
```

## Reactive state

| Member | Meaning |
| --- | --- |
| `items` | Rows in the current collection. |
| `totalCount` | Exact count when known, otherwise `null`. |
| `loading` | Whether a read is in progress. |
| `error` | Last relevant error, otherwise `null`. |
| `stale` | Whether visible rows require revalidation. |
| `schema` | Generated client-safe table metadata. |
| `fields` | Exposed schema keys. Advanced metadata. |
| `editableKeys` | Editable schema keys. Advanced metadata. |

## Reads and freshness

```ts
await exampleTable.fetch()
await exampleTable.refresh()
exampleTable.invalidate()

const entry = await exampleTable.getById(id)
```

## Mutations

```ts
const entry = await exampleTable.create({ title: 'First entry' })
await exampleTable.update(entry, { title: 'Updated entry' })
await exampleTable.remove(entry)
```

`create()` returns the actual server row. `update()` returns the server row or `null`, and `remove()` resolves only after server confirmation. `update()` and `remove()` accept either a primary-key value or a complete row from the same model. NSDB only extracts the generated primary key from a row; it never sends that row as the update payload. All async model operations reject with the original Supabase or runtime error.

## Advanced helpers

```ts
const draft = exampleTable.createDraft()

exampleTable.subscribe()
await exampleTable.unsubscribe()
```

`createDraft()` derives a local form draft from schema metadata. Realtime is opt-in and client-only.
