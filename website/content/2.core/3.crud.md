---
title: CRUD
description: Create, read, update, and remove rows with server-confirmed results.
---

## Create

```ts
const entry = await exampleTable.create({
  title: 'First entry',
})
```

The payload uses the generated `Insert` type. The result is the server-returned row, including database defaults and generated values. The Promise rejects if creation fails or Supabase does not return the created row.

## Read one row

```ts
const entry = await exampleTable.getById(id)
```

The result is a row or `null`. The lookup uses the generated primary key. An optional raw select can narrow the response:

```ts
const entry = await exampleTable.getById(id, 'id,title')
```

## Update

When the row is already available, pass it directly:

```ts
const entry = await exampleTable.create({ title: 'First entry' })

const updated = await exampleTable.update(entry, {
  title: 'Updated entry',
})
```

NSDB knows the generated primary key for the model. It extracts only that key from `entry`; the update payload remains exactly the second argument, so readonly values and included relations are never copied into the mutation.

The primary-key form remains available:

```ts
const entry = await exampleTable.update(id, {
  title: 'Updated entry',
})
```

The payload uses the generated `Update` type. The result is the real server row or `null`.

## Remove

By row:

```ts
await exampleTable.remove(entry)
```

By primary key:

```ts
await exampleTable.remove(id)
```

Row targets are especially useful when a model uses a custom key such as `slug` or `profile_uuid`: application code does not need to know the generated key name. The typed overload accepts a complete row from the same model. Composite-primary-key CRUD remains unsupported; use the low-level API for that advanced case.

Mutations are pessimistic: Supabase succeeds first, then NSDB updates local state. A failed operation rejects and leaves successful local data intact.

```ts
try {
  await exampleTable.remove(id)
} catch (error) {
  // Supabase code, message, details, and hint remain available.
}
```
