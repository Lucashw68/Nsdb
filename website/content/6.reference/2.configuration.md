## Common generator options

| Option | Type | Default | Purpose |
| --- | --- | --- | --- |
| `supabase.schema` | `string` | `'public'` | PostgreSQL schema to generate. |
| `supabase.projectId` | `string` | `''` | Hosted Supabase project for CLI type generation. |
| `supabase.dbUrl` | `string` | `''` | Direct PostgreSQL URL for self-hosting and exact metadata. |
| `supabase.linked` | `boolean` | `false` | Use the locally linked Supabase project. |
| `tables.include` | `string[]` | `[]` | Allowlist of generated tables. Mutually exclusive with `exclude`. |
| `tables.exclude` | `string[]` | `[]` | Tables omitted from generation. |
| `tables.columns` | policy record | `{}` | Per-column exposure rules. |

At least one type-generation source is needed: a project ID, linked project, database URL, or remote settings.

## Output paths

| Option | Default |
| --- | --- |
| `paths.types` | `types/database.types.ts` |
| `paths.metadata` | `nsdb/database.metadata.json` |
| `paths.enums` | `nsdb/enums.ts` |
| `paths.schemas` | `nsdb/schemas` |
| `paths.models` | `nsdb/models` |
| `paths.composables` | `nsdb/composables` |
| `paths.stores` | `stores` |
| `imports.databaseTypes` | `~~/types/database.types` |

All generators, module registration, and ownership-safe cleanup honor configured paths.

## Column policies

```ts
tables: {
  include: ['profiles'],
  columns: {
    profiles: {
      email: { editable: false },
      avatar_url: { hidden: true },
      internal_note: { serverOnly: true },
    },
  },
}
```

Each policy accepts `selectable`, `editable`, `hidden`, and `serverOnly` booleans. See [Column Exposure](/docs/advanced/column-exposure) for exact semantics.

## Advanced generator options

`templates.model`, `templates.schema`, `templates.useNsdbModel`, and `templates.store` replace the packaged templates. `generators.force` allows overwriting when supported. Custom templates are an advanced compatibility boundary and should retain public model contracts.

## Nuxt module options

| Option | Type | Default |
| --- | --- | --- |
| `withComponents` | `boolean` | `true` |
| `componentsPrefix` | `string` | `'Nsdb'` |
| `withStores` | `boolean` | `true` |
| `autoImportModels` | `boolean` | `true` |

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nsdb: {
    withComponents: true,
    componentsPrefix: 'Nsdb',
    withStores: true,
    autoImportModels: true,
  },
})
```
