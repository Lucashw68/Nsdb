This is the public API candidate validated by `1.0.0-rc.1`. Generated table models are the recommended application surface.

## Generated model

```ts
const model = useExampleTable({ store: true })
```

### State and metadata

| Member | Type shape | Level |
| --- | --- | --- |
| `items` | `Ref<Row[]>` | Public |
| `totalCount` | `Ref<number \| null>` | Public |
| `loading` | `Ref<boolean>` | Public |
| `error` | `Ref<unknown>` | Public |
| `stale` | `Ref<boolean>` | Public |
| `schema` | generated metadata | Public |
| `fields` | schema keys | Advanced |
| `editableKeys` | editable schema keys | Advanced |

### Operations

| Signature | Return |
| --- | --- |
| `fetch(options?)` | `Promise<Row[]>` |
| `refresh(options?)` | `Promise<Row[]>` |
| `invalidate()` | `void` |
| `getById(id, select?)` | `Promise<Row \| null>` |
| `create(insert)` | `Promise<Row>` |
| `update(primaryKey, update)` / `update(row, update)` | `Promise<Row \| null>` |
| `remove(primaryKey)` / `remove(row)` | `Promise<void>` |
| `subscribe()` | `void` |
| `unsubscribe()` | `void \| Promise<void>` |
| `createDraft()` | schema-derived draft |

Async model operations reject with the original Supabase or runtime error. Mutations update local state only after server success.

For row-target mutations, `row` is a complete row from the same generated model. NSDB extracts its generated primary key and sends only the explicit `update` payload. Primary-key values remain supported. Composite-primary-key CRUD remains outside the generated model contract.

## Runtime composables

- `useSupabaseApi` — advanced dynamic database adapter.
- `useSupabaseApiStorage` — advanced Storage adapter.
- `useSupabaseModel` — generic model factory used by generated bindings.
- `useNsdbSchema` — generated schema access.
- `useNsdbProfile` — profile helper.

Advanced store factories are `createDbStore` and `createSingletonStore` when enabled by the module.

## Components

`NsdbList` and `NsdbForm` are public. The nested relation selector is internal and is not globally registered.

## Package boundaries

The package root exports the Nuxt module. Supported subpaths include the low-level APIs, singular runtime factories, public type paths, and store factories. Runtime directories, generator helpers, templates, scripts, and nested components are implementation details and are blocked by the export map.

## Error contracts

Generated models reject on failure and expose reactive `error` state. The low-level database and Storage APIs instead return discriminated `{ success, data, error }` objects; list responses also include `count`.
