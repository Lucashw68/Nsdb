title: Storage
description: Use the advanced Storage adapter while keeping file and database workflows explicit.
badge: Advanced
---

`useSupabaseApiStorage()` wraps Supabase Storage with normalized paths and discriminated response objects.

```ts
const storage = useSupabaseApiStorage()

const uploaded = await storage.upload(
  'avatars',
  'users/me.png',
  file,
)

if (!uploaded.success) {
  throw uploaded.error
}
```

Create a short-lived URL for a private object:

```ts
const signed = await storage.createSignedUrl(
  'avatars',
  'users/me.png',
  300,
)

const url = signed.success ? signed.data.signedUrl : null
```

## Available operations

Files: `list`, `upload`, `update`, `download`, `remove`, `getPublicUrl`, signed URL/upload helpers, `move`, and `copy`.

Buckets: `listBuckets`, `getBucket`, `createBucket`, `updateBucket`, `deleteBucket`, and `emptyBucket`.

`joinPath` and `normalizePath` remain advanced public path helpers.

::callout{type="warning" title="No cross-service transaction"}
NSDB does not claim that a Storage operation and a PostgreSQL mutation are atomic. Rollback, retry, and orphan cleanup remain application policy.
::

Storage authorization still belongs to Supabase Storage policies.
